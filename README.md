# Pong Game

A simple browser-based Pong game built with HTML, CSS, and JavaScript.

## Features
- Left paddle controlled by mouse and arrow keys
- Computer-controlled right paddle
- Bouncing ball
- Scoreboard
- Wall and paddle collision detection

## Run locally
1. Open `index.html` in a browser, or
2. Serve the folder with a local web server if preferred.
